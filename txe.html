🚀 CI/CD Pipeline

CI/CD automatically builds, tests, and deploys your application.

→

🔄 CI

Build & Test

→

✅ Test

Check for errors

→

🚀 CD

Deploy application

→

☁️ Production

Users access app

What is CI?

Continuous Integration means automatically building and testing the code whenever a developer pushes changes.

What is CD?

Continuous Deployment means automatically deploying the tested application to the server.

Example

Developer → GitHub → GitHub Actions → Test → Docker → AWS EC2 → Users
