Git & GitHub

A Beginner's Guide to Version Control and Code Collaboration

Git GitHub Difference Commands Workflow

What is Git?

Git is a distributed version control system. It is used to track changes in files and source code.

Version Control

Git keeps track of changes made to your project. You can see what changed and when it changed.

Local Tool

Git runs on your computer. You can create commits, branches and manage your project without internet.

Branches

Git allows developers to create branches so they can work on different features independently.

What is GitHub?

GitHub is a cloud-based platform where developers can store Git repositories and collaborate with other developers.

Remote Repository

GitHub stores your Git repository online so that you can access it from anywhere.

Collaboration

Developers can work together using pull requests, issues and branches.

CI/CD

GitHub Actions can automatically build, test and deploy applications.

Git vs GitHub

Git GitHub
Version control system Cloud-based development platform
Runs locally Runs primarily online
Tracks code changes Hosts Git repositories
Created by Linus Torvalds Owned by Microsoft

Important Git Commands

1. Initialize a Repository

git init

Creates a new Git repository inside the current folder.

2. Check Repository Status

git status

3. Add Files

git add .

Adds all changed files to the staging area.

4. Create a Commit

git commit -m "Initial commit"

5. Connect to GitHub

git remote add origin https://github.com/username/repository.git

6. Push Code to GitHub

git push -u origin main

7. Download a Repository

git clone https://github.com/username/repository.git

Basic Git + GitHub Workflow

1. Create your project 
mkdir my-project
cd my-project
2. Initialize Git 
git init
3. Create or modify files 
index.html
app.py
README.md
4. Stage the files 
git add .
5. Commit the changes 
git commit -m "Add project files"
6. Push to GitHub 
git push origin main

Git Branching

Branches allow developers to work on features without directly changing the main production code. 

# Create a branch
git branch feature-login

# Switch to the branch
git checkout feature-login

# Or create and switch
git checkout -b feature-login

# Merge the branch
git checkout main
git merge feature-login

Important GitHub Features

Repositories

Store and manage your source code and project files.

Pull Requests

Used to review and merge code changes into another branch.

Issues

Used to report bugs, track tasks and manage project work.

GitHub Actions

Automates CI/CD processes such as testing, building and deployment.
