Core Concepts

Instance Types

Determine the hardware of the host computer used for your instance. Each instance type offers different compute, memory, and storage capabilities.

  • General Purpose (t3, m5)
  • Compute Optimized (c5)
  • Memory Optimized (r5)

AMIs (Amazon Machine Images)

Provides the information required to launch an instance. You must specify an AMI when you launch an instance (e.g., Ubuntu, Amazon Linux, Windows Server).

  • OS & Software configuration
  • Launch permissions
  • Block device mapping

Security Groups

Acts as a virtual firewall for your EC2 instances to control incoming (inbound) and outgoing (outbound) traffic. They operate at the instance level.

  • Stateful rules
  • Default deny all inbound
  • Allow specific ports (e.g., 22, 80)

EBS Volumes

Persistent block storage volumes for use with Amazon EC2 instances. Think of it as a network-attached hard drive that survives instance termination.

  • GP2/GP3 (General Purpose SSD)
  • IO1/IO2 (Provisioned IOPS)
  • Can be snapshot for backups

Key Pairs

Public key cryptography used to encrypt and decrypt login information. AWS stores the public key, and you store the private key (.pem file).

  • Used for SSH (Linux)
  • Used to decrypt password (Windows)

Elastic IPs

A static, public IPv4 address designed for dynamic cloud computing. You can associate it with an instance to ensure the public IP doesn't change on reboot.

  • Static public address
  • Mask failure by remapping
